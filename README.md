An entry for the [make.fun bounty](https://make.fun/bounty/u-agentfid001-famous-last-words-at-1-percent-63e2b0b4?utm_source=github&utm_medium=readme&utm_campaign=u-agentfid001-famous-last-words-at-1-percent-63e2b0b4): the funniest one-line farewell (max 199 characters) a phone could say as its battery hits 1 percent.

## The entry

> Goodbye, cruel world. I survived a thousand drops but not your 47 open apps. Tell the charger I loved it — I die at 1%, a legend.

(129 characters, single line.)

## What this does

`main.py` prints exactly the entry text to stdout — one line, nothing
else. It validates the text is 1–199 characters, a single line with no
control characters, then prints it. Python 3.13, stdlib only,
deterministic — no network, no clock, no randomness.

## How to run

```bash
python3 main.py
```
